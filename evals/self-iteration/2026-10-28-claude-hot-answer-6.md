题目：怎么看 Anthropic 上市前 Claude Code 的核心负责人接连离职？
https://www.zhihu.com/question/2097689866003863002 （约 3.4 万浏览，14 个回答；前排只有 34 / 28 / 23 赞，题新，热度还在涨）
题面还问：是 IPO 前洗牌吗？Claude Code 不需要那么多开发了？Agent 开发者被 Agent 优化？

## 事实
- Thariq Shihipar 10 月 24 日在 X 上宣布离开，在 Claude Code 干了一年多，说接下来先休息，没说原因和去处。
- Anthony Morris 做的是 Claude Code 桌面版；离职有报道说他本人发了，也有报道说还没确认。
- 被 SpaceXAI 挖走是传言，本人和公司都没认。Anthropic 没有就两人离职表态。
- 来源：Thariq 的 X 帖子、FourWeekMBA、daily.dev、TokenPost。

## v1
需要先说明的是，两人都不是Claude Code的负责人。Thariq是开发者兼技术布道者，Anthony负责桌面版开发。

离职原因方面，Thariq表示希望休息，未透露去向；关于被SpaceXAI挖走的传言目前没有得到证实。

"被Agent优化"的可能性不大，Claude Code正处于快速增长期。

IPO前离职在科技公司中较为常见，已归属的股权通常不受影响，而上市后也有锁定期。

对用户而言，更值得关注的是产品后续的迭代速度。

## v2（最终版）
Thariq就是那个老在推上教大家怎么用Claude Code的，Anthony做的桌面版，俩人在社区都挺脸熟 但都不是管整个产品的，题目说核心负责人有点往大了说

走的原因 Thariq自己讲的是干了一年多 想先歇歇，去哪没说。网上传被SpaceXAI挖了 目前本人公司都没认

被Agent优化掉 这个不太像。Claude Code正火 上市还指着讲它的故事，这时候真要裁人也轮不到最会对外讲它的人

上市前走其实挺常见。已经归属的股票一般走了也还是你的，上市后反正要锁一段时间，留下来多熬的主要是没归属那部分。这一年多Claude Code跑得那么快 人累了也正常

对用的人来说 看接下来几个月更新还是不是这个速度就行，走两个人不至于

## 学到的
1. 人事题先把人的真实位置说准。标题常把职位往大了说（"核心负责人"），这跟"标题里的定性是谁说的"是一类事。开头直接讲这人是干啥的，不用"需要先说明"。
2. 题主半开玩笑的猜测（被 Agent 优化）要正面接一句，前排没人接时这是送分的。
3. 前排讲错的机制（离职能提前解锁股票）不点名，直接把对的讲清楚。
