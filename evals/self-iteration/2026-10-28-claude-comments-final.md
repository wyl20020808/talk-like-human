## 学到的东西

1. **专业评论要先接住评论区的气氛。** 这些回答底下大部分是梗，真人的专业评论很少，有也很短（"补一个习惯：……"）。所以开头先接一句梗或者认同，再说正经的，不然像突然闯进来讲课。
2. **评论区里有内行，要比他们深一层。** openclaude 那条评论区早就有人会换模型了，人家要的是"开源可控的客户端"。初版只教"改接口地址"太浅，改成了推荐有正经开源许可证的工具。
3. **把传言和事实分开。** "10T 参数""马斯克说 Opus 5T""梁文峰说 800B"在评论区传来传去，明说"没有可靠出处"本身就是专业价值。
4. **不和已有评论撞车。** 已经有人补过的点，不再重复。
5. **200 字只讲一件事。** 每条围绕一个点：一个机制、一个误区，或者几个具体的操作，不铺开讲全。
6. **守住的底线：** 不编"我用了半年"这类经历；专业内容不放错字；拿不准的数字不写（Haiku 5.5 的定价没查到官方来源，就没写价格）；该批评 Anthropic 的地方照样批评，不替它打广告。

## 10 条评论

### 1. 如何看待 claude 在国内封号如此严重，依然有大量死忠不停充？（1.3 万赞，一长串封号段子）
> 小写ok那条太狠了[飙泪笑] 说点正经的 封号一般不是看你像不像中国人 是看几样东西对不对得上：登录IP是不是机房或者老在换地区 付款卡的账单地址跟IP是不是一个地方 是不是几个人轮着用一个号 有没有走第三方镜像转发。这几样一冲突就容易触发风控。根上的原因是大陆本来就不在官方支持的地区里。死忠还在充 主要是写代码那块替代成本太高，真要长期用 先确认自己所在地区能不能合规用 别把项目押在随时会没的号上

### 2. Anthropic 新规禁止持续虐待 Claude，这意味着什么？（7226 赞，"养尊处优的大小姐，其实是邪神降临的容器"）
> 大小姐好歹还给自己留了个挂电话的权利[doge] 补个背景 这事其实不算全新，2025年Anthropic就给Opus 4加过一个功能：用户持续辱骂或者反复要有害内容 劝了几次都没用 模型可以自己结束这段对话。他们把这块研究叫model welfare，官方说法挺克制 意思是不确定模型有没有感受 但成本很低就先做了。对正常用户基本没影响，日常聊天碰不到，被结束的对话也能新开一个 或者回去改前面的消息重来

### 3. 如何评价 Anthropic 的下一个模型 Claude Mythos？（873 赞，"恐吓式营销""自家 CMS 有漏洞都没扫出来，医者不能自医"）
> CMS泄密这个确实丢人 不过两件事得分开看。这次是内容管理系统配置错了 草稿页面能被公开访问，属于网站运维的低级失误，跟模型能不能找漏洞不是一回事，就像安全公司前台忘了锁门 不代表他们家的扫描器不行。至于是不是恐吓营销 我觉得得看后面的动作：要是真像草稿里说的 先只开放给做网络防御的机构，那更接近漏洞披露的老路数。10T参数那个说法目前没看到可靠出处 先别当真

### 4. 为什么 claude code 都不让用了，好多人还是不放弃？（519 赞，推荐用泄露源码改的 openclaude 配 DeepSeek）
> 提醒一句 泄露出来的源码不等于开源，没有许可证 改了再分发法律上是有风险的。更实际的是安全问题：这类工具能直接在你电脑上跑命令 读写文件，用来路不明的改版 等于把终端权限交给不认识的人。只是想换模型的话 官方客户端改个ANTHROPIC_BASE_URL就能接兼容接口；真想要开源 自己可控的客户端，opencode、aider这种本来就带正经开源许可证的，比魔改泄露版踏实

### 5. 为什么 Claude 的逻辑推理能力远超其他大模型？（229 赞，"GPT 形式推理更强，Claude 强在任务的真实脏度"）
> 任务脏度这个角度挺好 补一句能拿来量化的：形式推理看数学竞赛题，"脏任务"可以看SWE-bench Verified这种从真实GitHub issue里抽出来的题，或者Terminal-Bench这种让模型在终端里自己装依赖 跑命令 排错的测试。Claude这几代拉开差距主要就在这类上，纯数学竞赛反而没那么突出，正好对上你说的。不过benchmark也会被针对性优化，最后还是得放到自己的代码库里跑一跑才知道

### 6. Anthropic 凭 Claude Code 收入翻倍，该模型有何突出之处？（165 赞，"Claude Code 不是模型是 Agent 框架"，引了官方成本估算）
> 题目确实问歪了 Claude Code是壳 模型是Sonnet和Opus。补几个压成本的点 比文档里那个平均数实用：一是上下文 别一个对话聊一整天，任务换了就/clear，长了用/compact压一下，token大头都耗在反复带着的上下文上。二是模型分工 计划和难的架构问题用Opus，日常改代码用Sonnet，/model里能切。三是反复读的大文件和系统提示走缓存，缓存读取比正常输入便宜一个数量级。这几样做到 账单差别很大

### 7. 有没有可能 2026 年 Anthropic 还在用 MHA+Dense MLP 的模型架构？（160 赞，引马斯克说 Sonnet 1T、Opus 5T，从降价推测转向 MoE）
> MoE基本是共识了 问题在稀疏到什么程度。不过有两个前提我会打个问号：马斯克那个1T、5T没有任何官方出处，拿来当基准不太稳。另外用价格倒推架构要小心，API定价里除了算力还有毛利、批处理折扣、缓存命中率、硬件代际，Opus降价同期也换了更新的推理硬件，不一定全是MoE带来的。1M上下文那条同意，纯MHA的KV cache扛不住，但具体是GQA、稀疏注意力还是别的压缩，外面确实没人知道

### 8. Anthropic 推出新模型 Claude Haiku，轻量模型降价提速对行业有何影响？（63 赞，适合当子 Agent；"一本书分五次放入只要五分之一的价"）
> 子Agent那个用法很对 不过分五次放入那段我没看明白，就算分段计价真是这样，把一本书拆成五段分开问，模型每次只看到五分之一，跨章节的问题就答不了了，省下的钱是拿效果换的。真想省钱更该看缓存：同一本书反复问，第一次写进缓存，后面读缓存只要正常输入十分之一左右的价，不急的活再走Batch API还能打五折，两样叠起来比拆书靠谱多了

### 9. 如何看待 Anthropic 提交 IPO 申请？（79 赞，拆 S-1 的五类股票，创始人和长期利益信托控制公司）
> 这结构确实有点SEELE那味了 补个背景方便理解为啥这么设计：Anthropic本身是公益公司（PBC），法律上允许董事会在股东回报之外考虑公司使命，长期利益信托（LTBT）是2023年就设好的，信托成员跟公司没有经济利益关系。所以这次上市更像把原来那套结构原样搬进公开市场。对买股票的人来说，买的是分红权不是话语权，公司要是为了安全推迟发模型，股东基本拦不住，这个风险得自己掂量

### 10. 如何顺畅的使用 Claude Code？（三种模式、先用 Plan 模式规划）
> 写得挺细 补几个日常很顶用的：一是项目根目录放个CLAUDE.md 写清楚技术栈 跑测试的命令 代码规范，每次启动都会自动读，不用回回重复交代，第一次可以用/init让它自己生成个初稿。二是改坏了别慌，连按两下Esc能回到之前的某一步重来。三是对话长了用/compact压缩，换任务就/clear，不然越聊越慢还越贵。四是常用的提示词可以存成自定义斜杠命令，一敲就出来
