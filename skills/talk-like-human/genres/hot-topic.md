# 热点题、热榜仿写

用法：写热榜题、新闻题、争议题时读，和 [long-answer.md](long-answer.md) 一起用。开头、横着看一批、方括号表情、不搬前排见闻这几条见 core/hard-rules.md，这里不重复。

## 1. 热点争议题（2026-10-28，Claude 热题两篇）
- **500 字左右的热点题：先站进读者的场子，再甩一张收据**（学习轮 6，4 题）。前排 12 篇在 150–900 字，三五百字最多。拿赞的形状是一个态度（替谁说话、骂谁）加一个可核实的硬东西，让读者自己得出结论：书里二十多个科研资助编号配一只双头虾；鸡脖泥 3800 元一吨，折一斤不到两块；县城工厂的工资和社保。我四篇都写成了解读，Q2、Q4 还不知不觉站到了读者对面（读者在替比亚迪说话、在气姆巴佩没诚意，我在讲统计口径、替公关团队算分寸）。动笔前先按 platforms/zhihu.md"先看读者情绪站在哪"过一遍；手里的数先想能不能直接甩出来（principles 第 17 条"把两个数字摆在一起"），不要拿去写解释。
- **找原话是固定动作**（7 篇里第 3 次碰到标题失真：灵魂、核心负责人、读博没意义）。热题标题常把一段话压成一句耸动的结论，前排几百个回答也未必有人去对。
- 前排几乎全是段子和吐槽时（神棍公司、大小姐、百合番），正经回答的价值是把**谁说的**分清：标题里的定性常常是爆料人的原话，不是公司的说法。写成"这是 xx 的说法，公司回应是 xx"。
- 公司的说法也照着原意写，不往大里说（"不确定有没有意识"不等于"认为有灵魂"），也不帮它洗。
- 正经答里要有一个读者一看就懂的比方，最好是自己造的、贴着知乎人群的（程序员注释里画佛祖保佑永无BUG）。前排已经用过的比方（工厂开工请道士）不搬。
- 结尾接一下前排的情绪（吐槽、捂脸），读者觉得是同一个场子里的人，不是来科普的。
- **财报、数字题**（Anthropic 上市）：先拆读者最困惑的那个数，用生活里的比方讲会计概念（807 亿非现金亏损 → 答应朋友按房价还半套房，房子涨了账上欠得多，兜里钱没动）。前排内行都在用术语时，比方就是能多给的那一层。
- 前排有内行拆账时不跟他们比细，挑一条最影响读者判断的结论翻成大白话，其余不搬。
- 百分比、总额这种抽象数，换成读者能想象的单位（违规收入 5%～7% → 最少九百多万个 20 刀的号连交九个月）。前排只说"肯定不是散户"时，把数摆出来就是多给的一层。
- 前排是受害者在出气时，正经分析的结尾要接住这股火（封了不退钱、规则它说了算），不然读者会觉得我在替公司说话。
- 涉及股票只讲公司和规则，不说该不该买；结尾落在一件能等到的事（发行价），不写总结句。
- 产品发布题，去读官方原文里**自己承认的短板和计费细节**（Duet：会搞错轻重缓急、私人杂事是弱项、后台巡检算额度）。前排大多在复述卖点或表态，这两样对想用的人最实在。
- 比方贴着读者身份造：知乎多是上班的人，"爱主动的实习生，判断不准比不主动还烦"一听就懂。
- 人事题先把人的真实位置说准，标题常把职位往大了说（"核心负责人"）。开头直接讲这人是干啥的，不用"需要先说明"。
- 题主半开玩笑的猜测（"Agent 开发者被 Agent 优化"）要正面接一句，前排没人接时这是送分的。
- 前排有两种情绪同时存在（焦虑、反感说教），两个都接：中间给焦虑的人一条能用的建议，结尾接反感。
- 用户说不要格式时：一段只放一件事，段落本身就是结构，不靠加粗和列表。


## 2. 仿写热榜长答（2026-10-28 第 1 轮）
- 先量高赞的形状：字数、段落数、图数、编号和加粗。科普题常是"一句一段 + 每几段一张图"，语言/方法题常是"编号分点 + 例句"。照着形状写。
- 方向跟前排，内容找前排的空：前排都讲过的压短，篇幅给没人讲、有数据的那条。
- 图只画数据图和对照表（matplotlib，存 /Users/apple/talk-like-human/evals/hot-images/），不用别人的照片；前排实物照片多时，靠图里的信息量补。
- **前排停在"会变 X"的地方，往下算一步就是空子**（第 2 轮太阳题：前排都说轨道"变成椭圆"，有人直接说"得数学好的人算算"）。算出来以后，给结果怎么随条件变（按哪个月消失列一张图），比只给一个数信息量大。
- 拆高赞时把**没出处的说法**单独记下来（"乳固体 4%""会诱发地震""全球掉 10–15℃"）。正文不点名，直接摆查到的数，或者自己算一笔能量账。
- **没亲手做过的实操题，不跟高赞拼参数**（第 2 轮牛排题：第一名锅温、秒数写得极细）。写明"照常见做法整理"，篇幅给能用的判断方法（听噼啪声判断水烧干没有）。字数因此比第一名短，就在文档里写清短在哪、为什么不补。
- 高赞有加粗小标题时，形状跟上，但标题写成问句或具体名词（"那3克水在干嘛"），不写"第一段：高温上色"这种讲义格式。
- **选题看热度也看回答数**（第 3 轮）：百万热度、两百多个回答的题，赞最多的往往是一两句段子，正经长答只有一两篇，空子比冷门题大。
- **题面新闻稿里的数先互相验算**（第 3 轮姆巴佩题）：同一段题面里，"中国 2200 万欧 = 全球 38%"和"全球赞助 3000 万美元"放在一起就对不上。前排只会直接引用，不会去做乘除。出处找不到原文的，写"没找到原文，按没核实处理"。
- **核实一个数时要问"它管的是哪笔钱"**（第 3 轮）：前排用的 80% 是真的，但那是代言分成，被套到了球衣收入上。数对不对、机制套没套错，要分开查。
- 前排说"X 不允许 Y，所以 Y 用不上"时，去查 Y 有没有真的发生过（第 3 轮网贷题：暴力催收在印度出过人命，后来的整顿就是从这里开始的）。前排讲错的地方（这题、离职能提前解锁股票）都不点名纠正，单列一节或直接把对的讲清楚。
- 外国单位要换算两遍：1 crore = 1000 万，21000 crore = 2100 亿卢比。

- 带图发布的操作见 zhihu-publish skill。
