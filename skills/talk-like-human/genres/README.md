# 先认题，再选写法

动笔前先想：这是哪一种题？读者想要的是什么？不同的题，拿赞的方式完全不一样。认完题，读对应的文件。

| 题型 | 拿赞的方式 | 读 |
|---|---|---|
| 求助题（怎么办、值不值、怎么选） | 先站队，给具体时间、数字、步骤，写清执行时卡在哪；情感、家务事的求助常常一个比方或反问就够 | long-answer.md + short-answer.md |
| 知识题、分析题 | 一条主线，算账、找机制、同条件对比 | long-answer.md |
| 热点、新闻、争议题 | 找原话，分清谁说的，接住读者情绪 | hot-topic.md + long-answer.md |
| 日常题、人际题、职场题 | 态度、一句洞察、能直接用的小招，短 | short-answer.md |
| 情绪题、代际梗（"老登"） | 自己的年份和一个时间锚，不讲梗的来历 | short-answer.md |
| 梗题、"有哪些"、脑洞、概念题 | 顺着玩，演出来，不抬杠 | 下面第 2 节 + examples/answers.md |
| 格式题（冷知识、相见恨晚、教我一个知识） | 先看第一名在玩什么，常常是段子、在家能试的小把戏或马上能用的小招 | 下面第 3 节 |
| 专栏文章 | 开头短（真实的由头或一个场景），给观点起名，吐槽或反讽收尾 | article.md + long-answer.md |
| 公开评论、作者回复 | 接一个点，看一层是玩笑还是正经；作者回复可以长一点、补细节 | comment.md |
| QQ、微信聊天 | 看关系，接最后一句，按用户自己的口气 | chat.md |
| 要用梗、要"网感"（评论、短答、梗题都可能） | 一条评论一个梗，回答一两处；公共梗可用，别人原创的不搬 | meme.md |

## 1. 先审题

- 先看题目有没有偷换概念、前提有没有错，有就先指出来（自我迭代第 1 轮：题目把"累计动捕 1000 小时"写成了"甄子丹一个人动捕 1000 小时"）。
- **带优越感或预设的题，前排几乎都在反问题目**（学习轮 9：60hz 题第一名嘲"默认全世界都打 CSGO"；换皮抽卡题前排拿获奖的抽卡游戏当反例）。**不带优越感的求助题、比较题，题面里的条件也常被翻**（学习轮 13，4 题）：离职后要等一个月？第一名说公司一周内就让你走；周五谁来定作业？有人反问作业是孩子的；古代苦水相当于自来水？前三名都说差远了。动笔前把题面里每个条件过一遍，问它成不成立。
- **泛问题、老问题被推上来，先查最近出了什么事**（学习轮 18，2 题）：问吃猪油健不健康，前三名全在说 2024 年曝光的油罐车混装食用油，猪油不进油罐车所以反而放心；问今年万圣节为什么没气氛，前三名全在说武汉江汉路网约车司机被困车里四小时、车被砸。我一个讲脂肪酸比例，一个说没查到。这类题读者带着最近的新闻来，先搜"题目关键词 + 最近"，查不到再写通用答案。
- 抓题眼（第 3 轮 Q4、Q9）："相见恨晚"要的是大多数人不知道的，不是大路货；"真能实现吗"问的是怎么做、要多少成本，不是新闻出处。新闻背景一句带过，篇幅给题眼。
- 题眼要连限定词一起抓，小到一个字（学习轮 5 Q2、Q3；轮 6 Q3：题面是"牛肉**味**丸"，名字已经写了"味"，我却说它冒充牛肉）："在颠覆性的技术面前"是这句话成立的条件，前排单拎出来讲，我直接忽略了；"留条后路"是题主的脑洞，前排顺着假设推一步再算账否掉，我只答了"不会"。
- 假设题、脑洞题要接着玩下去，给出一个有创意的答案。不要用"谁也做不到"一句话否定前提，那是抬杠（Q6 金苹果）。

## 2. 梗题、"有哪些"、脑洞、概念题
动笔前先想一下：这是哪一种题？
- **梗题**（"××奢靡到什么地步""××有多离谱"）：顺着梗玩，真人在这种题下面几乎都在讲段子，先想段子，正经信息放最后一句。学习轮 17 许家印题第一名（1.5 万赞）92 字：饮水机装冰红茶、周四麦当劳单点、打车勾选全部车型；我规则在却写成了分红数据。
- **"有哪些"题**：直接演出来、举出来（比如模仿台词，括号里写动作），不要去讲解分类。
- **脑洞题**：顺着假设玩（见第 1 节）。
- **概念题**（"如何理解××"）：用一个故事把它演一遍，比讲出处更打动人。例子从读者手边的别处找，不用题目里那个人自己的标准例子（学习轮 17，2 题）：第一性原理第一名（9013 赞）讲煮白萝卜为什么苦，不讲马斯克的电池；事以密成第一名讲别人的建议都带着他自己的前提，配小马过河，不讲韩非原文。
- **题目里的词按字面接**（学习轮 13，2 题）：问一万多词汇量怎么来的，第一名（418 赞）直接把词频表前一万个词贴了出来；问历史上最骑虎难下的人，有一篇写辽史里真有人攥着老虎耳朵骑在虎背上。都是我没想到的。不是每题都要这样，但动笔前想一下：照字面做一遍会是什么样？

用户直接问我、明显需要事实的时候，事实优先；梗可以放在最后一句。

## 3. 格式题（2026-10-29 学习轮 4）
- 历史大题里"冷知识"三个字是格式。第一名（3.3 万赞）是"洗澡水忽冷忽热 → 另一半对你忽冷忽热，八成有人和你共享"，"物理事实 → 一句反转到人"；第二梯队是在家能试的小把戏（猫刚睡醒用它尾巴捅它脸，它先揍尾巴）。正经科普在这种题下排不上。
- "相见恨晚的思维方式"这类清单题，写法见 long-answer.md 第 6 节"清单题挑一个讲透"。
- "可不可以莫名其妙地教我一个知识"（学习轮 18，7400 万浏览）：前三名都是能马上用的小招，还常给它起个名字：买房前去查附近有没有新开的肯德基、蜜雪（2.4 万赞）；"蜜雪冰城效应"，出门找小吃街先搜蜜雪（2.2 万赞，75 字）；吵架要攻击不要解释（2 万赞）。我写的是海獭睡觉手拉手，冷知识没进前三。
