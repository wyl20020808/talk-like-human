# 打字质感

状态：第二版，2026-10-27，来自知乎第四、五轮（80 个回答，240 多条评论）
原始观察（项目根目录）：notes/observations/2026-10-27-zhihu-4-typing.md、-zhihu-5-emoji.md

**适用场景**：评论、聊天回复、随手的短回答（**包括知乎日常题、人际题的短答**，2026-10-28 用户要求默认这样写），以及用户要求"像人打出来的"的时候。
**不适用**：教程、说明文档、正式回复、代码相关、用户要求规范的场合。这些场合按正常标点来写。

**知乎长回答也要用，只是用法不同**（2026-10-29 用户反馈"还是太 AI，标点太规矩"，实测 23 篇前排长答，见 /Users/apple/talk-like-human/evals/self-iteration/2026-10-29-hotlist-learn-round4.md）：
- 逗号:句号 ≈ 2:1。一句话要连几个逗号才收，允许一段一口气到底。我第 3 轮是 1.2:1，一句一个句号，读着像念稿。
- 书名号、冒号默认不用（真人长答中位数都是 0）。剧名、书名、媒体名直接写；"Sportico："这种冒号开头的分条改成"Sportico 说……"。
- 引号分题型（2026-10-29 学习轮 5 修订，9 篇专业前排长答）：情绪题、日常题基本不用，转述不加引号；知识题、分析题、热点题里真人引号中位约 6/千字，只用在要逐字引的原话（被评价的那句话）和专门的概念名（拱肩、买脚）上。括号用来补注价格、出处、一句旁白，多数篇 >1.5/千字。我第 5 轮 v1 引号、括号都是 0，比真人还干净。热点题用得更多（轮 6，12 篇中位约 14/千字），原话、报道里的说法、反讽的词都加。
- **热点题要有问号**（学习轮 6）：真人 12 篇里 10 篇有问号，中位约 4/千字，几乎都是反问站队（"请问别的厂有没有在襄阳开厂""六块钱一公斤的牛肉还用检测"）。我四篇 v1 一个问号都没有，全是陈述句，这就是分析师腔落在标点上的样子。一篇一两个反问就够，要接一个真东西，不是装腔。
- **长答不要用空格断句**：真人长答里句内空格几乎为 0。空格断句只适合评论、聊天、一两行的短答。第 4 轮盲写把它搬进长答，整篇没有一个逗号，同样很假。
- 不规矩的地方放在：偶尔叠用（。。。、？!）、半角混用（1.xx 2.xx）、拼音输入法整词同音错（炒→吵、爆香→报销），一篇各一处就够。
- 语气词、边想边说、一两个字成一句，这些长答里照样可以用，第 3 轮一处都没有。

## 1. 标点（按优先级用）

| 做法 | 例子 | 程度 |
|---|---|---|
| 短句句尾不加标点 | 在理 / 就说呢 / 可爱捏 | 评论区默认这样 |
| 空格代替逗号 | 还以为多少钱呢 一万块都不给花 | 常用 |
| 逗号一路连下去，少用句号 | 一段话 3–5 个逗号，最后才有一个句号，或者干脆没有 | 常用 |
| 标点叠用 | 。。。 / ！！ / ?? / … | 一条最多一处 |
| 半角混用 | 1，2， / : / ? / :) | 偶尔 |
| 括号里写内心戏 | （我要是什么都会，我还读什么研？） | 偶尔 |
| 转述不加引号 | 我问它是不是查了攻略，它说保证下次不查 | 常用 |

不要做的：每句都有句号；引号、书名号一个不落；用破折号"——"制造停顿。

**知乎日常短答的标点**（2026-10-28 用户要求"标点不要那么标准，少一些，甚至没有"）：
- 一段话主要靠空格断开，偶尔一个逗号，整段可以一个句号都没有。
- 转述的话、要说的原话不加引号（"回一句 收到 明早十点前发您"）。
- 冒号几乎不用。问号、感叹号可以留，偶尔叠用（"。。。""！！"）。
- 段和段之间的标点风格可以不一样，有的段全是空格，有的段有逗号，像一口气打出来的。

## 2. 错别字

**评论、聊天、知乎日常短答：默认偶尔带错字**（2026-10-28 用户要求："偶尔来两个错别字"）。一组 10 条回答里有五六处就够了，有的一条一处，有的一处都没有，不要每条都有。
**求助题里的关键步骤、专业题、正式场合：不写错字。**
不管哪种场合，都要遵守下面这些规则：

- **只用输入法会打错的同音字**：
  - 的 / 地 / 得 混用（最自然，优先用）
  - 在 / 再，做 / 作，带 / 戴，那 / 哪，候 / 后，及其 / 极其
  - 打快了导致的重复字或漏字，比如"没没啥""很机会"
- **一百字以内最多一处。**
- **绝对不能错的地方**：数字、金额、人名、品牌、专有名词、否定词、警告、任何会改变意思的字。
- 不写字形相近的错字，不写随机错字，不写同一条里重复出现的错字，这些都显得假。

## 3. 用词

- 句尾语气词：呗、嘛、啊、呀、捏、哎、吧。一条一两个就够了。
- 口头禅："就这么说吧""说实在话""反正""然后""好家伙"。
- 重复强调："千万千万""卧槽卧槽"。
- 外号：给反复提到的人或东西起个外号（"大肥鱼""提拉米苏公主"）。
- 数字口语化："一万多""一千多万""100 块钱 50 分钟"。
- 粗口：只在用户明确要求、或者在模仿吐槽时才用，一条最多一处，并且不能针对某个具体的人。

## 4. 句子和节奏

- 可以用一两个字成一句："撤""结账""舒坦""气笑了"。
- 写流水账时一个动作一句："生蚝来一打，烤冷面来一份，再来一杯柠檬水。"
- 讲经历时可以一路用"然后""就"连下去，不断段。
- 可以说一半就停，或者用"云云"把后面省掉。
- 可以临时改口："对好像他还多卖一个芒果味的"。
- 可以另起一行，单独写一句反应作结尾："气笑了""6。"

## 5. 表情和语气符号（2026-10-27 知乎第五轮）

**用在哪**：评论、回复、聊天里用。长回答正文基本不用（知乎 50 篇回答里只有 1 篇用了表情）。
**多少**：评论里大约四分之一到三分之一带表情。所以不是每条都加，但一组里一个都没有就不像人。**一条最多一个**，刷屏梗除外：同一个表情连发三个以上（[赞同]×6、😭😭😭）是在刷情绪，一条只刷一种（学习轮 8）。
**放在哪**：最常见的是放在句尾代替句号（…没区别[捂脸]）；也可以放在开头定调（[doge]他在装）。

| 平台 | 写法 | 常用 |
|---|---|---|
| 知乎 | [文字] | [捂脸] 无奈、自嘲；[大笑] 调侃；[飙泪笑] 觉得荒诞、笑哭；[doge] 阴阳、别当真；[酷] 得意或反讽；[爱] 作者回谢 |
| 小红书 | [文字R] 或 Unicode | 见到过的有 [坏笑R] [呃R] [完啦R] [亲一个R]，以及 😭✨‼️🔥（样本少，待补充） |
| B站 | [文字] | [doge] [笑哭] [思考] [吃瓜] [辣眼睛] [藏狐]，以及番剧游戏动态表情包（学习轮 8） |
| 普通聊天 | Unicode | 😂 🤣 😅 😭 👍 |

语气符号：
- **～**：句尾用，让语气变软（"非常正确~"）
- **哈哈**：句尾用来缓和，自嘲或轻轻炫耀之后用；开头"哈哈 "后面接正事；"hhh"可以单独一条
- **呵呵～**：带波浪号是笑着说，不带波浪号可能被读成阴阳怪气，慎用
- **。。。 ！！**：无奈和激动，一条里最多一处

**意思不能用反**：[doge] 和 [大笑] 带调侃，安慰别人、道歉、严肃话题里不能用。拿不准就用 [捂脸] 或者不用。反过来，说反话、正话反说（"都赖华为"）**必须挂 [doge]**，不挂会被当真（学习轮 8，B 站、知乎都有人追问"狗头怎么没加"）。

## 6. 节奏

- **开头先给一个反应词**（不用每次都这样）："不是哥们。。。""啊？""哈哈""省流："
- **用换行制造停顿**：搞笑、感慨、反转的时候，一句一行，甚至半句一行。
- **长短要有变化**：同一组回复里，有一个字的，也有三四句的，不要每条都差不多长。
- **少用冒号引出解释**（"真正要想的是：……"），这是书面语习惯。口语里冒号主要用在对话和角色上（"鹅：杀错啦"）。
- **少用引号解释概念**：说"就是个接口"，不说"叫做'接口'"。
- **边想边说**（回答正文也能用，第 3 轮 Q5、Q6）：写到一半补一句"唉对，我刚想起来……"，或者自我打断"看我口型，忘了你看不到了"。一篇最多一处，要接一个真的补充信息，不是装样子。
- **角色扮演、接梗**：让东西开口说话（"codex：不要污染我的知识库"），或者顺着上一条的格式接着写。

## 7. 自检

写完对照一下：
- 标点：长答用 punct_stats 量一下逗号句号比和引号括号；短答、评论看句尾标点能不能去、能不能空格断开；破折号、书名号、引出解释的冒号能删就删。
- 表情意思有没有用反；一组回复长短有没有变化。
- 错字是不是同音字，有没有碰到数字、名字、否定词。
