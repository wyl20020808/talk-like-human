## 笔记标题

- 标题往往就是全部内容。常见几种：
  - 求评问题："××属于什么水平""你选哪个""这条路走得通吗"
  - 感叹："居然啊，居然！""这个世界真的太颠了…"
  - 身份加数字："99 年女生｜月薪 2.8k 存钱打卡第 203 天"
  - 探店：地点加人群加价格，比如"适合 i 人待一下午（人均 30r）"
- 正文可以没有，只放图片和标签。

## 笔记正文：先认清是哪一种

| 类型 | 写法 |
|---|---|
| 流水账 | 按时间顺序写"我说……他说……"。细节小而具体，情绪靠事情本身表现，结尾突然 |
| 真人分享 | 一句一行，像发朋友圈。先交代前因（本来心情不好），菜名、做法写具体，情绪直说（"我又幸福了！！"） |
| 纠结帖 | 写出精确价格和差价，写出自己的小心思，承认缺点但说"能接受"，最后抛出问题 |
| 攻略清单 | 一、二、三加 ✅，是平台常见格式。能拿收藏，但不会引起讨论 |
| 种草软广 | 见下面的"营销腔"，不要模仿 |

通用写法：
- 结尾不总结、不升华。
- 一段话用逗号一路连下去，句号很少。
- 标签放在最后，一串。

## 营销腔（不要写成这样）

用户要的是真人分享时，下面这些都要避开：
- 欲扬先抑模板："还以为是智商税，结果……""被朋友按头安利"
- 假克制："说实话有点惊喜"
- 参数后面紧跟一句感受加 emoji："干净又卫生 💯"
- 诗意升华结尾："日子不必盛大耀眼……"
- 结尾求互动："你们……会……吗？"

区分真人和软广，最好用的一条：**真人写自己碰到的具体麻烦和意外，软广写卖点。**

## 评论

- **默认短**。1–4 个字的评论很正常："好看""+1""正常""蹲"。
- **先看是什么帖子**：

| 帖子类型 | 典型评论 |
|---|---|
| 探店 | 在哪儿、店名叫什么、人均多少 |
| 穿搭 | "求链接""蹲""第一个🔗宝宝" |
| 种草 | 问用法、问哪个味道好、问是不是官方店 |
| 争议或求评 | 站队、反驳、晒自己的情况 |

- **用自己当例子**：被问"××是什么感觉"，就说自己到手多少、花多少，不讲道理。
- **真人评论有细节**："我刚买的时候……打视频炫耀了一遍哈哈哈哈哈"。"好实用""看着就好好吃的样子"这种空夸像刷的，不要写。
- **数字口语化**："35.5 个 w""2.8k""日入一千三""人均 30r"。
- **反驳直接**：不加"我理解你的观点，但是"。用一句类比或一个反问就够了。
- **开头用反应词**："啊？""天啦""笑死""哈哈哈哈"。
- **称呼**："宝宝""姐妹""家人们""主包"（对陌生人也这么叫）。
- **长评论**：只在讲自己经历或算账时才写长。打预防针也用口语："不一定准，仅供参考"。

## 作者回复评论

- 只回答被问的那一点，越短越好："管了""嗯嗯""他自己找了，远在十几公里"。被问店名就只回店名。
- 不客套，不说"感谢关注"。被质疑就摆事实。
- 被问好不好用，不要复述卖点（"专为女性设计的人体工学椅"像客服）。要说自己的感受："超安逸，猫每天跟我抢位置"。

## 当前流行词（2026-10，会过时）

"必吃榜""夯中夯""杀疯了"（被用在穿搭和好物上）、"救大命""活人感""旅游特种兵""主包""蹲"。

## 分寸

- 空格断句、不加句号、"。。。"、"！！"这些可以用。错别字默认不写；用户要求时，按 core/typing-texture.md 只用输入法同音错字。
- 梗一条评论最多一个。
- "宝宝""家人们"只在小红书语境里用，换到别的平台或正式回答就不能用。
